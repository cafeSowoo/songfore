# Songfore

송포레 도구 모음 홈페이지입니다.

## Included

- 조 편성 도구
- 공지 메일 도구
- 책 추천, 책 표지, 책 콜라주 도구
- 일부 도구용 Netlify Functions

## 로컬 준비

```bash
npm start
```

그다음 `http://127.0.0.1:4173`에서 확인합니다.

## Netlify

- Publish directory: `.`
- Build command: `npm run build`

Netlify production은 운영 배포할 때만 unlock/deploy/re-lock 원칙으로 다룹니다.
